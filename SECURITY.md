# Security Policy

## Reporting a Vulnerability

This repository is proprietary software owned by ThumbPin Pvt Ltd (see
[LICENSE](LICENSE)) and is not open source. If you discover a security
vulnerability in this codebase or in any ThumbPin product, please report
it privately and do not disclose it publicly.

- Email: thumbpincreatives@gmail.com
- Do not open a public issue, pull request, or discussion describing the
  vulnerability.
- Include as much detail as possible: affected component, steps to
  reproduce, potential impact, and any suggested remediation.

## Response Process

1. We will acknowledge receipt of your report as soon as possible.
2. We will investigate and validate the issue.
3. We will work on a fix and coordinate remediation before any public
   disclosure.
4. We will notify you once the issue has been resolved.

## Scope

This policy covers the ThumbPin frontend client application in this
repository. Unauthorized security testing against production systems or
user data without prior written authorization is not permitted.

## Confidentiality

As this is proprietary, non-open-source software, please treat any
vulnerability details as confidential until ThumbPin Pvt Ltd confirms
resolution and disclosure timing.
