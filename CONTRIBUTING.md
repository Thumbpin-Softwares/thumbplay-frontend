# Contributing

This repository is proprietary software owned by ThumbPin Pvt Ltd (see
[LICENSE](LICENSE)) and is not open source. Contributions are limited to
authorized employees, contractors, and collaborators of ThumbPin Pvt Ltd.
External pull requests or contributions are not accepted.

## Before You Start

- Make sure you have signed any required contractor/employee agreement
  covering intellectual property and confidentiality.
- Read the [Code of Conduct](CODE_OF_CONDUCT.md).
- Report any security issues per [SECURITY.md](SECURITY.md) instead of
  filing a public issue.

## Workflow

1. Create a branch off `main` using a descriptive name
   (e.g. `feat/collection-view-modal`, `fix/upload-retry`).
2. Keep commits focused and write clear commit messages.
3. Run linting and tests locally before opening a pull request:
   ```
   pnpm lint
   ```
4. Open a pull request against `main` and request review from a
   teammate.
5. Address review feedback and squash/merge once approved.

## Code Style

- Follow the existing patterns in the codebase (component structure,
  naming, file organization) rather than introducing new conventions.
- Run `pnpm lint` and fix any issues before requesting review.

## Confidentiality

Do not share code, credentials, design assets, or internal discussions
from this repository outside of ThumbPin Pvt Ltd without authorization.
